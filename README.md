# Simple JS Calculator

A clean and simple web calculator built using HTML, CSS, and vanilla JavaScript.

## Features
- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Clear display functionality (C button)
- Responsive dark-themed UI

## Live Demo
You can check out the live project here: <a href="https://artiahmeti.github.io/Calculator/" target="_blank">Calculator Live</a>

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
